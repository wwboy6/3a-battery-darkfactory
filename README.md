# Dark Factory by 3A Battery

A repo for a Dark Factory agent team that perform software development without human-in-the-loop. This is a project for [WeAreDevelopers x BAND present: Dark Factory (hackathon edition)](https://lablab.ai/ai-hackathons/wearedevelopers-hackathon)

## Info

Team: 3A Battery

Track: Pocketful

## Folder structure

- README.md
- FACTORY.md         - this factory: seats, design choices, costs, failure handling
- mandates/          - one .md per seat, named after the seat, at least three; each
                     names the seat's harness and model
- room.json          - the room, downloaded from Band
- result/
  - stage-1/         - factory result for stage, with Dockerfile, RUN.md, source
  - stage-2/
  - stage-3/
  - stage-4/
